# collect/ — dataset build pipeline (Track A accuracy instances)

The editable source of truth is **`botcamp_curated.yaml`** — fixtures
(frozen market-data windows) and instances (curated botcamp strategies with
status `ready` / `todo` / `decline`). The header of that file documents how
to add or edit an instance.

Pipeline (all via the repo Makefile):

| Command          | What it does                                                        | Needs network |
|------------------|---------------------------------------------------------------------|---------------|
| `make normalize` | Botcamp CSV → `corpus/botcamp.jsonl` (all 88 strategies, categorized) | no          |
| `make fixtures`  | Record yaml-declared regime fixtures → `datasets/fixtures/<id>/`     | yes (Hyperliquid) |
| `make goldens`   | Run every `ready` reference over its fixtures → `instance.json` + `golden/` | no    |

`fixtures` and `goldens` run under the **condor-simple** environment
(`uv run --project ~/condor-simple`) because the backtest engine and the
Hyperliquid client live there. Fixtures are frozen once recorded (delete a
dir to deliberately re-record — but note Hyperliquid candle history only
reaches back ~7 months, so old windows become unrecordable). Golden diffs
are meaningful: re-running `make goldens` after editing a reference SHOWS
you the behavior change in `git diff`; commit it consciously.

Instance layout:

```
datasets/instances/<id>/
  prompt.md               # authored: user-voice task, explicit params
  reference/strategy.py   # authored (ready only): PARAMS + decide(candles, ctx)
  instance.json           # GENERATED by make goldens — do not edit
  golden/<fixture>/       # GENERATED: intents.jsonl + summary.json
```
